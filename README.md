# Ο Άγιος Βασίλης στον ουρανό

Χριστουγεννιάτικο παιχνίδι για το κινητό: την ώρα που ορίζουν οι γονείς, ο Άγιος Βασίλης έρχεται με το έλκηθρο μέσα από την κάμερα, μιλάει στο παιδί, και φεύγοντας γράφει το όνομά του στον ουρανό με αστερόσκονη.

Ανοίγει από το link του GitHub Pages. Η κάμερα χρειάζεται https.

Αρχεία:
- `index.html`: όλο το παιχνίδι.
- `santa-final.mp4`: το βίντεο (39 δευτερόλεπτα) χωρίς πράσινο φόντο. Πάνω μισό η εικόνα, κάτω μισό η διαφάνεια.
- `santa-final.mp3`: ο ήχος του βίντεο (φωνή και καλπασμός). Παίζει ξεχωριστά και ακολουθεί την εικόνα.
